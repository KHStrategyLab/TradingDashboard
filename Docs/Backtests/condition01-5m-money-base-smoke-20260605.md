이 파일은 UTF-8 기준으로 작성됨.

## 목적

01번 검색식에서 들어오는 분봉 재료를 백테스트에서 먼저 숫자로 고정한다.

이번 테스트는 수익 검증이 아니라 다음 흐름이 코드로 이어지는지 확인하는 smoke test다.

```text
검색식 재료
-> 5분봉 40억 이상 거래대금
-> 최근 완료 3분봉 3개 평균 거래대금 30억 이상
-> 전일고가 돌파
-> 일봉 Bollinger Band(20,2) 상단 돌파
-> 5분 기준봉 후보 확정
-> 1분봉 눌림/재돌파 트리거 확인
-> 구조 매도 신호 확인
```

## 미래값 누수 수정

처음 만든 버전은 당일 일봉 Bollinger 상단 돌파를 계산할 때 당일 최종 종가를 사용했다.

이것은 09:00~12:00 장중 검색식 조건을 백테스트하는 데 사용할 수 없는 미래값이다.

수정 후에는 다음 방식으로 계산한다.

```text
전일 이전 19개 일봉 종가 + 현재 5분봉 종가
-> 임시 당일 Bollinger Band(20,2) 상단 계산
-> 현재 5분봉 종가가 임시 상단을 돌파했는지 확인
```

종가청산 비교도 KRX는 15:30, NXT는 20:00까지만 본다.

## 판정

처음 종가청산 결과가 좋아 보였던 이유는 당일 최종 종가를 이용한 Bollinger 조건 누수였다.

미래값을 제거하니 종가청산은 오히려 크게 나빠졌다.

따라서 이 테스트의 결론은 다음이다.

```text
조건01 5분 40억 기준봉 후보를 코드로 재현하는 경로는 열렸다.
하지만 현재 1분 트리거와 매도 구조는 아직 매수전략으로 채택할 수준이 아니다.
```

## 확인된 점

- 기존 DataStore 원천 데이터는 수정하지 않았다.
- 결과는 Runs 폴더에만 저장했다.
- KRX/NXT는 Code + Market 기준으로 분리해 읽었다.
- 고정 N% 손절/익절은 사용하지 않았다.
- 당일 일봉 Bollinger 상단은 장중 5분봉 종가를 임시 종가로 계산한다.
