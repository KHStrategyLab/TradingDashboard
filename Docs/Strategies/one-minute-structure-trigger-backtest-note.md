# 1분 구조 트리거/손절 백테스트 메모

작성일: 2026-06-06

## 목적

5분 기준 신호 이후 바로 매수하지 않고, 1분봉에서 가장 단순한 재상승 구조가 확인되는지 본다.

이 실험은 백테스트 전용이다.
실주문, Live Orders, 주문 API, RiskGuard 실주문 흐름에는 연결하지 않는다.

## 매수 트리거

매수는 완성 1분봉 기준으로만 판단한다.

- 0봉전 1분봉 종가가 1봉전 1분봉 고가를 돌파한다.
- 0봉전 1분봉은 양봉이다.
- 0봉전 1분봉 종가가 1분 5이평 위에 있다.
- 거래량 5이평이 직전보다 꺾이지 않는다.
- 0봉전 1분봉 거래량이 거래량 5이평을 크게 밑돌지 않는다.

이 조건은 사용자가 말한 “거래가 늘면서/거래가 유지되면서”를 거래량 이평선 방향으로 수치화한 첫 기준이다.

## 손절 트리거

손절도 완성 1분봉 기준으로만 판단한다.

- 0봉전 1분봉 종가가 1봉전 1분봉 저가를 훼손하면 구조 훼손으로 본다.

고정 `-N%` 손절이 아니라 작은 분봉 구조가 깨졌는지를 본다.

## 실행 명령

```text
--backtest-five-preday-range-rsi2-1m-prev-high-break-prev-low-stop
```

## 해석 원칙

- 이번 실험은 “더 좋은 매수 시점”과 “안 살 이유”를 찾기 위한 비교 대상이다.
- 수익률 자체보다 손절이 먼저 나오는 종목의 공통 구조를 확인한다.
- 이 조건이 맞지 않으면 폐기하거나 보조 필터로 낮춘다.
