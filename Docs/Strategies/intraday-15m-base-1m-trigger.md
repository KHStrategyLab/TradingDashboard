# Slot 5 - 당일 15분 기준봉 + 1분 트리거 단타

이 전략은 기존 D+ 기준봉 추적 전략이 아니다.

오늘 조건검색식에 들어온 종목 중에서 당일 거래대금과 가격 흐름이 살아 있고,
완성된 15분봉 기준봉이 생긴 뒤 5분/3분/1분 순서로 매수 가능성을 좁히는 당일 전용 단타 슬롯이다.

## 후보 소스

- 조건검색식 당일 편입 종목
- `IsIntradayPreCandidate = true` 또는 당일 기준 `GateBaseCandleOffset = 0`
- 기존 D+ 게이트 통과가 필수는 아니다
- 보유 종목은 중복 매수 정책을 따른다

## 필터

- 매매 시간: 09:05 ~ 14:50
- 등락률: 7% 이상 24% 이하
- 당일 거래대금: 300억 이상
- 전략 분봉 장부: 1분, 3분, 5분, 15분 준비

## 15분 기준봉

완성된 15분봉만 사용한다.
진행 중인 0봉전 15분봉은 기준봉으로 쓰지 않는다.

기준봉 조건:

- 양봉
- 시가 대비 종가 +1.5% 이상
- 봉 거래대금 20억 이상
- 현재가가 기준봉 중심값 위
- 현재가가 기준봉 고가 대비 +2.5% 이상 멀지 않을 것

기준봉 중심값:

```text
BaseCenter = (BaseHigh + BaseLow) / 2
```

## 5분 / 3분 확인

5분:

- MA5 >= MA20
- 현재 5분봉 양봉
- 현재 5분봉 종가가 기준봉 중심값 위

3분:

- 현재 3분봉 양봉
- 현재 3분봉 종가가 직전 3분봉 종가 위
- 현재 3분봉 종가가 MA5 위

## 1분 트리거

이 슬롯은 강의 원문을 그대로 복사하지 않고 우리 1분 이평선 전략을 섞는다.

1분:

- 현재 1분봉 고가가 직전 1분봉 고가를 돌파
- 현재 1분봉 양봉
- 현재 1분봉 종가가 MA60 위
- 1분 MA5 >= 1분 MA60
- 현재 1분봉 거래량이 직전 5봉 평균 거래량의 1.5배 이상
- 거래량 MA5 >= 거래량 MA60

## 0B / 0D 최종 확인

0B 체결 흐름과 0D 호가 요약은 전략 컨텍스트에 연결되어 있다.

0B는 종목별/시장별 메모리 큐에 최근 60초 체결 샘플만 보관한다.
파일 저장은 하지 않는다.

0D는 현재 선택 종목의 호가창에서 들어오는 호가 요약을 사용한다.
따라서 선택되지 않은 종목은 0B 흐름은 볼 수 있지만, 0D 지지 확인은 대기 상태가 될 수 있다.
이것은 안전 우선 설계다.

현재 Slot 5의 최종 실시간 게이트:

- 0B 틱이 최근 10초 이내여야 한다.
- 마지막 체결이 매수 우위여야 한다.
- 최근 60초 매수 체결량이 매도 체결량보다 많아야 한다.
- 최근 60초 매수 체결량 비율이 55% 이상이어야 한다.
- 최근 60초 매수 체결대금이 5천만 원 이상이어야 한다.
- 0D 호가가 최근 15초 이내여야 한다.
- 매수잔량 비율이 45% 이상이어야 한다.
- 현재 가격이 최우선 매수호가 아래로 무너지지 않아야 한다.

이 값들은 첫 기준값이다.
백테스트와 장중 관찰을 통해 완화 또는 강화할 수 있다.

## 주문 안전

현재 단계의 목적은 Progress와 알림 검증이다.

실주문 연결은 0B/0D 컨텍스트 연결, 백테스트, 장중 관찰 후 진행한다.
Live Orders가 켜져 있어도 이 전략은 0B 최종 확인 단계가 연결되기 전까지 주문 handoff를 허용하지 않는다.
