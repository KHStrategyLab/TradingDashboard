# 30분봉 600개 기준선 계산 메모

이 파일은 UTF-8 기준으로 작성됨.

## 목적

30분봉 600개 기준선은 5분봉 매수 후보가 공중에 뜬 돌파인지, 실제 상위 구조의 지지/저항 안에서 만들어진 소마디인지 확인하기 위한 지도다.

5분봉에서 `1차 상승 이후 허리 위 기준봉 생성 -> 고가 돌파 매수`를 보려면, 먼저 30분봉에서 힘이 모인 가격대가 있어야 한다.

## 핵심 원칙

- 30분 기준선은 KRX 전일종가 기준가를 덮어쓰지 않는다.
- 30분 기준선은 실주문 기준가가 아니라 백테스트/전략 판단용 상위 구조 레벨이다.
- 기준선은 단순 산술 50%가 아니라, 30분봉 600개 안에서 전고점/전저점/지지/저항이 반복된 가격 클러스터다.
- 5분봉 허리나 기준봉이 30분 주요 지지 위에서 만들어지면 더 의미가 있다.
- 5분봉 돌파 직후 30분 주요 저항까지 공간이 얇으면 안 살 이유가 된다.

## 현재 구현

서비스:

`Services/Backtests/ThirtyMinuteBaselineService.cs`

실행:

```powershell
dotnet run --no-build --project .\TradingDashboard.csproj -- --backtest-30m-baseline-scan
```

출력:

`Storage/Backtests/Runs/SORON_30m_baseline_scan_yyyyMMddHHmmss/thirty_minute_baselines.csv`

## 계산 방식

1. 종목별 `Code + Market` 30분봉 파일을 읽는다.
2. 최근 600개 30분봉을 사용한다.
3. 좌우 3봉 기준 로컬 고점/저점을 찾는다.
4. 가까운 피벗 가격을 클러스터링한다.
5. 각 클러스터에 대해 지지 터치, 저항 터치, 거래대금, 최근성을 점수화한다.
6. 현재가 기준 가장 가까운 하단 지지선과 상단 저항선을 찾는다.
7. 상단 저항까지 남은 공간을 `BreakoutRoomPct`로 기록한다.

## 해석

`SUPPORT_WITH_ROOM`

30분 기준 지지 근처에 있고 위쪽 저항까지 공간이 남아 있다. 5분 소마디를 볼 만한 후보.

`SUPPORT_BUT_ROOM_THIN`

지지는 있지만 위쪽 저항까지 공간이 얇다. 돌파 직후 추격은 조심.

`NEAR_30M_RESISTANCE`

상위 저항에 붙어 있다. 안 살 이유 후보.

`ROOM_THIN`

가까운 저항까지 공간이 부족하다.

`OPEN_MIDDLE`

지지/저항 사이 중간 영역이다. 5분/1분 구조 확인이 더 필요하다.

## 다음 적용 후보

5분봉 MA200 회복 후 MA60 눌림 지지, 기준봉 고가 돌파 전략에 붙인다.

필터 후보:

- 5분 기준봉 또는 눌림 저점이 30분 주요 지지선 위인가.
- 매수 후보 가격에서 30분 주요 저항까지 최소 2~3% 이상 공간이 있는가.
- 30분 기준선 아래로 다시 밀린다면 해당 소마디를 폐기할 것인가.

## 고정 문장

30분 600봉 기준선은 “살 자리”를 만드는 것이 아니라, “안 살 이유”를 먼저 찾기 위한 상위 구조 지도다.
