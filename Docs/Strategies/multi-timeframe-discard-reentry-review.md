# 다중 시간축 버릴종목 / 재매수 판정 설계

작성일: 2026-06-06

## 목적

이 문서는 손절이 나온 종목을 즉시 폐기할지, 계속 추적할지, 재매수 후보로 되살릴지 판단하기 위한 기준서다.

핵심은 다음이다.

손절은 종목 폐기가 아니다.
손절은 위험 위치에서 빠지는 행동이다.

다만 손절 후에도 모든 종목을 계속 들고 가면 잡음이 커진다.
따라서 일봉부터 분봉까지 순서대로 확인해, 진짜 버릴 종목과 다시 볼 종목을 나눈다.

## 최상위 원칙

1. 데이터가 섞이면 판단하지 않는다.
2. KRX 기준가는 색상/기준가의 최상위 기준으로 유지한다.
3. SOR ON / AL 분봉은 실행과 백테스트의 실제 움직임 판단에 사용한다.
4. NXT 가능 종목은 KRX/NXT/AL 데이터가 섞이지 않게 Market을 명시한다.
5. 실주문과 직접 연결하지 않는다. 먼저 백테스트/리얼테스트/스냅샷 검증으로만 운용한다.

## 판정 순서

판정은 아래 순서로만 진행한다.
아래 단계에서 탈락하면 하위 분봉 신호가 좋아도 매수하지 않는다.

1. 일봉 위치
2. 30분봉 큰 구조
3. 15분봉 기준마디 / 허리
4. 5분봉 기준봉 / 눌림
5. 1분봉 손절 / 재매수 트리거

## 1단계: 일봉 위치

일봉은 이 종목을 오늘 다룰 가치가 있는지 확인하는 단계다.

확인 항목:

- 최근 큰 거래대금이 들어온 기준봉이 있는가
- 전일고가 또는 최근 고점을 돌파했는가
- 현재가가 큰 저항 바로 앞인가
- 큰 음봉 중심 또는 고가 부근에서 막히는가
- 거래대금은 큰데 고가권을 지키지 못하는가
- 일봉 5/20/60선 구조가 완전히 무너져 있는가

버릴 후보:

- 전일고가 돌파 후 다시 전일고가 아래로 깊게 밀림
- 큰 거래대금이 들어왔는데 윗꼬리만 길게 남김
- 최근 큰 저항 바로 아래에서 힘이 꺾임
- 일봉 기준봉 몸통 중심 아래로 내려온 뒤 회복 실패

계속 볼 후보:

- 전일고가 위 또는 기준봉 중심 위에서 버팀
- 거래대금이 들어온 뒤 조정이지만 고가권을 크게 훼손하지 않음
- 5선/20선/60선 중 최소 하나의 지지가 살아 있음

## 2단계: 30분봉 큰 구조

30분봉은 당일 또는 며칠간의 큰 마디가 살아 있는지 확인한다.

확인 항목:

- 큰 상승마디가 형성되었는가
- 큰 마디의 허리 위에서 가격이 유지되는가
- 30분봉 고점/저점이 계속 낮아지는가
- 거래량 증가 후 가격 전진이 멈췄는가

버릴 후보:

- 30분 기준마디 허리 아래에서 저항받음
- 30분 고점과 저점이 동시에 낮아짐
- 거래량은 유지되는데 가격이 하락 방향으로만 반응함

계속 볼 후보:

- 30분 허리 위에서 횡보 또는 약한 눌림
- 직전 고점을 다시 노릴 수 있는 구조
- 거래량 감소 조정 후 거래량 재증가 준비

## 3단계: 15분봉 기준마디 / 허리

15분봉은 매수 금지 여부를 결정하는 핵심 구조다.

확인 항목:

- 15분 기준봉이 살아 있는가
- 기준봉 몸통 절반 이상을 지키는가
- 15분 MA5/MA20 위 또는 근처에서 버티는가
- 큰 양봉 뒤 다음 15분봉이 고점 실패 음봉으로 바뀌는가

버릴 후보:

- 15분 기준봉 허리 아래 마감
- 15분 MA5/MA20 동시 이탈 후 회복 실패
- 15분 윗꼬리 후 다음 봉이 음봉화
- 15분 저점이 낮아지며 기준마디가 끊김

계속 볼 후보:

- 15분 허리 위 지지
- 15분 눌림이 얕고 거래량이 줄어듦
- 15분 고점 재돌파 가능 구간

## 4단계: 5분봉 기준봉 / 눌림

5분봉은 실제 매수 후보의 골격이다.

확인 항목:

- 5분 40억 이상 또는 조건식에서 돈이 들어온 봉이 있는가
- 5분 기준봉 저가와 몸통 중심을 지키는가
- 첫눌림이 MA5/MA10/MA20 부근에서 지지되는가
- 전일고가 위에서 눌림이 진행되는가
- 5분 거래대금은 큰데 가격 전진이 멈췄는가

버릴 후보:

- 5분 기준봉 저가 이탈
- 5분 기준봉 몸통 절반 아래 마감
- 전일고가 아래로 재진입 후 회복 실패
- 40억 봉 여러 개 뒤 고점 갱신 실패
- 거래대금은 유지되는데 종가가 계속 저가권

계속 볼 후보:

- 첫눌림이 MA5/MA10/MA20 중 하나에서 지지
- 전일고가 위에서 재돌파 준비
- 거래량이 줄어들며 가격이 크게 밀리지 않음

## 5단계: 1분봉 손절 / 재매수

1분봉은 실행 트리거다.
단, 1분 신호는 상위 구조가 살아 있을 때만 사용한다.

현재 테스트 중인 기본 손절:

- 1분봉 완성봉 종가가 직전 1분봉 저가 아래 마감

이 손절은 종목 폐기가 아니다.
상위 구조가 살아 있으면 계속 추적한다.

재매수 후보 1: MA20 회복형

- 손절 후 1분봉이 MA20 아래를 본 적 있음
- 이후 양봉으로 MA20 위 회복

재매수 후보 2: MA10 리셋 + 20봉 고가 돌파형

- 손절 후 1분봉 종가가 MA10 이하로 내려온 적 있음
- 이후 1분봉 종가가 직전 20봉 고가를 돌파
- 양봉이어야 함

현재 관찰:

- MA20 회복형은 빠르게 되살아나는 종목을 잘 잡을 수 있다.
- MA10 리셋 + 20봉 고가 돌파형은 더 강한 확인이지만, 늦은 추격이 될 수 있다.
- 따라서 재매수는 반드시 5분/15분 구조 생존 확인과 함께 써야 한다.

## 최종 판정 태그

각 손절/재매수 후보는 아래 태그 중 하나를 가진다.

### DISCARD

진짜 버릴 종목.

조건 예:

- 일봉 기준봉 중심 훼손
- 30분/15분 허리 아래 저항
- 5분 기준봉 저가 이탈
- 전일고가 아래 재진입 후 회복 실패
- 거래대금은 큰데 가격 전진이 전혀 없음

### WATCH

손절했지만 계속 볼 종목.

조건 예:

- 일봉/15분/5분 구조는 살아 있음
- 1분만 흔들려 손절됨
- 거래량 감소 조정 후 가격이 크게 밀리지 않음

### REBUY_CANDIDATE

재매수 후보.

조건 예:

- WATCH 상태에서 1분 MA20 회복
- 또는 MA10 이하 리셋 후 20봉 고가 돌파
- 5분 기준봉 중심 또는 전일고가 위 유지

### REBUY_BLOCK

1분 재매수 신호는 떴지만 상위 구조 때문에 막는 상태.

조건 예:

- 1분 20봉 고가 돌파는 나왔지만 5분 기준봉 저가 아래
- 15분 허리 아래
- 일봉 큰 저항 바로 앞

## 차트팩 설계

백테스트에서 손절 또는 재매수 후보가 나오면 아래 차트를 저장한다.

1. 일봉 차트
   - 기준봉
   - 전일고가
   - 최근 고점/저점
   - MA5/20/60/120/240

2. 30분봉 차트
   - 큰 마디 시작점
   - 마디 고점/저점
   - 허리 후보
   - 거래량/거래대금

3. 15분봉 차트
   - 기준마디
   - 허리
   - MA5/20/60

4. 5분봉 차트
   - 조건식 돈 들어온 봉
   - 전일고가
   - 첫눌림
   - 기준봉 고가/중심/저가
   - 첫 매수/손절/재매수

5. 1분봉 차트
   - 1분 손절봉
   - MA10/MA20
   - 20봉 고가선
   - 재매수봉
   - 재매수 후 최고가/최저가

## 백테스트 산출물

각 거래마다 아래 값을 저장한다.

- Code
- Market
- FirstEntryTime
- FirstStopTime
- ReentrySignalTime
- FinalExitTime
- DailyVerdict
- M30Verdict
- M15Verdict
- M5Verdict
- M1Verdict
- FinalVerdict: DISCARD / WATCH / REBUY_CANDIDATE / REBUY_BLOCK
- DiscardReasons
- RebuyReasons
- MaxFavorableExcursion
- MaxAdverseExcursion

## 다음 구현 순서

1. 기존 재매수 백테스트 결과에서 성공/실패 재매수 샘플을 고른다.
2. 각 샘플의 일봉/30분/15분/5분/1분 차트팩을 자동 저장한다.
3. 차트팩과 숫자 판정표를 같은 폴더에 저장한다.
4. 먼저 사람이 눈으로 확인한다.
5. 확인된 패턴을 DISCARD / WATCH / REBUY_BLOCK 규칙으로 승격한다.
6. 그 뒤에만 전략 조건에 반영한다.

## 현재 결론

재매수는 가능하다.
하지만 재매수 신호 하나만으로는 부족하다.

진짜 핵심은 손절 후에도 상위 구조가 살아 있는지 확인하는 것이다.

즉, 앞으로의 판정은 다음 문장으로 요약한다.

1분봉은 방아쇠다.
5분봉은 전술이다.
15분봉은 구조다.
30분봉은 흐름이다.
일봉은 다룰 가치다.
